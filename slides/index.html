과거 vs 현대 LLM, 뭐가 같고 다를까?

파트 1.5 · 15분

같은 점

  • 다음에 올 말을 예측한다
  • 오차를 줄이며 학습한다
  • 역전파로 가중치를 고친다
VS

다른 점

  • 모델의 크기 (가중치 수)
  • 학습한 글의 양
  • 사람의 지시를 따르도록 추가로 다듬는 과정

원리는 같은데, 이 차이가 결과를 얼마나 바꿀까요? 직접 확인해 봐요!

파트 2 · 과거 LLM 타임머신 탑승!

30분
오늘의 과거 LLM
KoGPT2 (2021년)

GPT-2(2019)와 같은 구조로 한국어를 배운 모델.
가중치 약 1억 2천5백만 개. 현대 LLM보다 훨씬 작아요.

이 모델의 특징
  • 질문에 '답'하기보다 글을 '이어 써요'
  • 엉뚱한 말이나 그럴듯한 거짓말이 많아요
  • "그~", "예." 같은 말버릇이 튀어나와요
실습 방법
  • 사이트 → 📼 과거 LLM (한국어로 입력해요)
  • 모델이 여러분 노트북에서 직접 돌아가요 (처음 한 번 내려받기)
  • '관찰' 표시를 하면 🃏 환각 도감에 모여요
사이트 → 📼 과거 LLM

오늘 던진 질문을, 반대쪽 모델에게도 똑같이 물어보고 비교해요.

1⚖️ 비교 리포트 → 📊 리포트 만들기 (3분)
2과거와 현대의 답을 비교하며 차이 메모, 발표할 질문 1개 고르기 (7분)
3조별로 '가장 차이가 큰 질문' 발표하기 · 🖥 발표 모드 (6분)
4투표로 가장 인상적인 비교 뽑기 (4분)

체감 포인트: 이어 쓰기만 하던 모델과 지시를 따르는 모델의 차이가 어떻게 보이나요?

겨우 '다음 말 예측'인데, 왜 이렇게 달라졌을까?

과거 LLM

  • 작은 모델
  • 적은 학습량
  • 글을 이어 쓰기만 함

현대 LLM

  • 훨씬 큰 모델
  • 방대한 학습량
  • 사람의 지시를 따르도록 다듬음

결국 LLM은 '다음에 올 말의 확률'을 계산하는 모델이에요.

그런데 규모와 훈련이 쌓이면서, 시험 문제 풀이, 번역, 코딩 같은 일에서 때때로 사람 수준 이상의 모습도 보여줘요.
