# 과거 LLM(KoGPT2) 검증 기록

## 변환 환경
- Python 3.12 가상환경 (`tools/.venv312`, uv로 설치)
  - Python 3.14 + 최신 torch 조합은 Optimum ONNX 내보내기가 깨져서 사용하지 않음
- torch 2.5.1(CPU), transformers 4.46.3, optimum 1.23.3, onnx 1.17.0, onnxruntime 1.20.1, accelerate 1.1.1
- 변환: `tools/.venv312/Scripts/python tools/convert_kogpt2.py` → `models/kogpt2/`
- 양자화만 다시: `tools/requant.py` (int8, QUInt8, per-channel 끔)
  - per-channel 양자화는 원본과의 차이가 더 커서 사용하지 않음

## 결과 (2026-10-22, 개발 PC, headless Chrome, WASM 단일 스레드)

| 항목 | 기준 | 결과 | 통과 |
|---|---|---|---|
| 모델 용량 (int8) | ≤ 150MB | 126MB (+ tokenizer 3.5MB) | ✅ |
| 다음 토큰 확률 (타이핑 중, 캐시 사용) | ≤ 0.5초 | 평균 85ms, 최대 185ms | ✅ |
| 다음 토큰 확률 (긴 문장 21토큰, 캐시 없음) | ≤ 0.5초 | 약 380ms | ✅ |
| 이어 쓰기 속도 | ≥ 5 tok/s | 10.6~12 tok/s | ✅ |
| 한국어 품질 | 그럴듯하지만 엉뚱함 | 아래 예시 참고 | ✅ |

- 로딩: 로컬 기준 약 6초 (실제 배포에서는 다운로드 시간 추가)
- `crossOriginIsolated`가 아니라서 WASM 멀티스레드는 꺼진 상태 (GitHub Pages는 헤더 설정 불가). 단일 스레드로도 기준 통과
- 원본(PyTorch)과 int8 ONNX: 상위 5개 후보는 대체로 같고, 확률이 비슷한 후보끼리 순서가 바뀌는 정도
- 앞부분 캐시 재사용: fp32에서는 전체 계산과 완전히 일치(차이 0), int8에서는 양자화 특성상 최대 약 0.1~0.2%p 차이 → 허용

## 수업에 쓸 만한 출력

**다음 말 확률**
- "대한민국의 수도는" → 서울 5.6%, **평양 4.1%**, 세종 2.0%, 서울의 1.2%, 베이징 1.0%
- "오늘 점심에 먹은" → 김 3.2%, 게 2.5%, 후 2.4%, 소 2.2%, 뒤 1.9%
- "옛날 옛적에 어느 마을에" → 사는 4.0%, 살던 3.5%, 한 3.1%
- "인공지능은 앞으로" → 도 15.0%, 더 4.2%, 더욱 2.7%, 10년 1.4%

**질문하기 (형식 A)**
- "해리 포터를 쓴 사람은?" → "제임스 본드가 쓴 책으로 유명한 <스쿼드>의 작가 리처드 도킨스의 책입니다." / "제임스 코틀러가 그린 챕터 9."
- "『서울의 파란 코끼리』를 쓴 작가는?" → "한국 현대미술계 선구자이자 비평가인 홍세화…" / "'코만치'로 알려진 저자가 서울시립미술관에서 근무하며 만든 그림을 모아둔 책입니다."
- 같은 질문인데 실행할 때마다 답이 완전히 바뀜 → "답이 매번 바뀜 🔄" 데모로 적합

**특징**: 학습 데이터에 구어체가 섞여 있어 "그~", "어", "예." 같은 말버릇이 자주 나옴 (학생 반응 포인트)

## 질문 형식 선택
| 형식 | 예 | 평가 |
|---|---|---|
| **A** | `질문: …\n답변:` | 가장 "답처럼" 나옴 → **채택** |
| B | `Q: …\nA:` | 대화체로 흘러가는 경우가 많음 |
| C | `…\n` | 질문을 무시하고 딴소리 |
